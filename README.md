# NORTH Workspace

Адаптивный личный кабинет на Bootstrap 5.3.3 и JavaScript.

## Запуск

Откройте `index.html` в браузере. Bootstrap включен локально, установка зависимостей и сборка не нужны.

## Интерфейс

Общая оболочка для шести разделов, desktop sidebar, мобильное меню Offcanvas, breadcrumbs и переключатель рабочего контекста. Используется hash-навигация. Данные примера не сохраняются и не отправляются на сервер.

## Навигация и фокус

Массив `routes` в `app.js` используется для desktop и mobile навигации. Переход из открытого меню откладывается до `hidden.bs.offcanvas`. После перехода фокус устанавливается на заголовок раздела. При обычном закрытии фокус возвращается на кнопку меню, если она видима.

При ширине от 992px открытый Offcanvas закрывается. В Chromium проверено удаление backdrop, снятие блокировки прокрутки и перевод фокуса на заголовок после перехода с 390px на 1440px.

Обработчики устанавливаются один раз на весь срок жизни страницы. Смена разделов заменяет только содержимое, не регистрируя новые обработчики. Отдельного API уничтожения shell в этой версии нет.

## Файлы

- `index.html` - оболочка.
- `app.js` - маршруты, содержимое и обработка событий.
- `styles.css` - оформление.
- `bootstrap.min.css`, `bootstrap.bundle.min.js` - Bootstrap 5.3.3, MIT.

Это самостоятельный пример на JavaScript, без Vite и TypeScript.
